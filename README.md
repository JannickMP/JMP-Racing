# JMP-Racing

A low-poly sim-arcade racer with real tyre physics and crash damage: GT3 cars and karts on Monza, Spa and a fictional circuit. Race AI opponents, or race friends online through Steam. Early test builds, so expect rough edges.

## Download

**[Get the latest installer](https://github.com/JannickMP/JMP-Racing/releases/latest)**: under *Assets*, download `JMP-Racing-Setup-<version>.exe`. It's for Windows 10 and 11 (64-bit).

1. Run the installer and follow the steps. It installs for you only, with no admin prompt, and you can choose a desktop shortcut.
   - Windows may say *Windows protected your PC*, because the game isn't signed yet. Click **More info**, then **Run anyway**.
2. Start Steam and log in **before** starting the game. Online play goes through Steam, which shows you as playing *Spacewar* until the game has its own Steam page.
3. Start JMP-Racing, and set up your wheel, pad or keyboard under **Settings > Controls**.

To remove it: **Windows Settings > Apps > JMP-Racing > Uninstall**. Your settings and replays stay, for when you install it again.

## Updates

When a new version is out, the game's start menu says so. Press **Update**, then **Restart now** once it's ready. The game downloads only the parts that changed, checks them and restarts on the new version. Everyone in an online race needs the same version.

Played it when it was called Ridgeline? Install JMP-Racing once: your settings and replays move over the first time it starts.
